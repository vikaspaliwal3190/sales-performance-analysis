# Dashboard Screenshot Checklist

Capture screenshots from your **actual Power BI report** after reconciliation. Use legible crop sizes, consistent filters, and no customer-identifying information.

- [ ] `01-executive-overview.png` — KPI cards, sales trend, category/region contribution, date context visible.
- [ ] `02-product-profitability.png` — product sales vs margin and low-margin table; labels readable.
- [ ] `03-discount-analysis.png` — discount bands, sales/profit/margin, note that association is not causation.
- [ ] `04-regional-customer-analysis.png` — regional contribution and customer/segment comparison.
- [ ] `05-model-view.png` — optional screenshot of star schema with readable relationships and no private server details.
- [ ] `06-qa-reconciliation.png` — optional QA page showing reconciled metrics, with sensitive information removed.
- [ ] `07-mobile-or-accessibility.png` — optional mobile layout or accessibility review evidence.

Before committing:
- Remove personal/customer data and sensitive filters.
- Check currency, units, date range and metric definitions are visible.
- Do not use preliminary numbers in public screenshots unless clearly marked preliminary.
- Do not present conceptual mockups as screenshots of the completed report.
- Keep screenshots in PNG or compressed JPEG and use descriptive filenames.
